# 西天取经智能招聘网络(XiyouRecruitment)

基于OpenAgents的多智能体协作招聘评估系统，为观音菩萨提供智能化的妖怪简历筛选服务。


### 演示视频（3分钟）

- **演示视频链接**：`https://www.bilibili.com/video/BV1TSB6BdEZx/?spm_id_from=333.1387.list.card_archive.click&vd_source=786ad4bf84a4683685f644011a4c3919`


## 项目简介

身为雷音寺有限公司的HR，观音菩萨面临海量妖怪简历筛选难题。本项目基于OpenAgents构建多智能体协作的招聘评估系统，通过5个专业智能体协同工作，实现从简历解析到结果汇总的完整评估流程。

## 系统架构

```
简历输入 
    ↓
简历解析Agent 
    ↓
路由决策Agent 
    ↓
    ├─→ 核心团队评估Agent
    ├─→ 配角安排Agent
    └─→ 人才发展Agent
    ↓
决策结果输出
    ↓
    ├─→ 保存评估报告到 Artifact
    └─→ 发布评估结果到 Feed
```

## 智能体说明

1. **简历解析Agent**：解析简历，提取结构化信息
2. **路由决策Agent**：根据候选人特征智能分流
3. **核心团队评估Agent**：评估核心团队成员
4. **配角安排Agent**：评估81难配角演员
5. **人才发展Agent**：为落选者提供发展建议

## 演示流程

### 1. 启动服务

```bash
# 终端1：启动网络
cd hackathons/networks/xiyou-recruitment-network
openagents network start ./network.yaml


# 终端3-7：启动5个Agent
openagents agent start ./agents/resume_parser.yaml
openagents agent start ./agents/router.yaml
openagents agent start ./agents/core_team.yaml
openagents agent start ./agents/supporting_role.yaml
openagents agent start ./agents/talent_dev.yaml
```

### 3. 打开Studio

访问 http://localhost:8700，连接到网络，进入"recruitment"频道。
